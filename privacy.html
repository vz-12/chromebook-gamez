VOIDRUNNER · privacy

Last updated 3 October 2026

VOIDRUNNER is a free browser game. It never asks for your real name, email address or age. Accounts are optional: an account is a name you choose and a password, nothing more. This page lists what the game keeps, where, and who else is involved in running it.

On your device

  • Your save: your callsign, progress, unlocks and settings, plus a random profile id the game makes up the first time you play. It is kept in your browser's storage for this site.
  • A save belongs to the address it was made on, and clearing this site's data in your browser deletes it.
  • If you sign in, a cookie that keeps you signed in. It holds a random code and nothing else, lasts 90 days from your last visit, and is deleted when you sign out.

On the game's server

  • Accounts, if you make one: the account name you chose, your password stored only as a one-way hash (nobody, including us, can read it back), a recovery code stored the same way, a copy of your save so it can follow you to other devices, and the profile ids of the devices you signed in on. Deleting the account (ACCOUNT → DELETE ACCOUNT in the game) erases all of it at once. The save on your own device is left as it is.
  • Leaderboards: the callsign you play under, your score and the run's stats, the time it was set, and your profile id. Every player's best is kept, not only the top places, so that anyone can look up where a callsign stands on the public leaderboard page. Callsigns, scores and placements are public, and so is the account name beside a signed-in player's runs. Profile ids are never shown to anyone.
  • Events and rewards: which event quests a profile id has completed, which reward skins a profile id holds, and which old callsign a profile claimed back after the move.
  • IP addresses, briefly, to stop abuse: how many new event profiles an address made today (kept for the day), failed sign-in and developer-login attempts (fifteen minutes), how many accounts an address made (an hour), and how often an address asked for a co-op relay (about three hours).
  • Co-op: to connect two players, each side's connection details, including network addresses, are passed through the server and deleted within an hour. During co-op, game data goes straight between the two players, or through Cloudflare's relay when a direct connection is not possible.
  • Request logs: the hosting service keeps routine logs of requests to the game's server for a few days.

Other services the game uses

  • Cloudflare hosts the game and its server.
  • Google Fonts supplies the game's fonts, and esm.sh supplies a code library it loads. Both see your browser's request for those files.
  • Google AdSense shows an occasional banner on the main menu, never during play. Google and its partners may use cookies to serve and measure ads. How Google uses this information is described at policies.google.com/technologies/partner-sites, and you can turn off personalized ads at adssettings.google.com.
